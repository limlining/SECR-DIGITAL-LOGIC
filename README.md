# SECR-DIGITAL-LOGIC

    Digital logic forms the basis of computers and all modern electronic devices. It is performed with the use of Boolean algebra-that is, true or false,
    1 or 0-along with logic gates such as AND, OR, and NOT-to process binary information. This combination of logic gates builds into digital circuits that
    perform arithmetic, hold information, and control various functions inside devices such as microprocessors and mobile phones. Digital logic thus uses
    high and low levels of voltage to represent the 1s and 0s, enabling complex actions based upon simple states.
    Basically, this project helped me understand the fundamental bases necessary for our programming skills. Without learning this course, 
    it would be much more difficult for us to comprehend the teaching in SECJ1013. The reason is that many programming concepts, for instance, 
    logic gates, Boolean expressions, binary, hexadecimal, and ASCII codes, are closely related to digital logic. Through this project, I can see the connection 
    between hardware logic and programming more clearly.

# 🔬PROJECT

![PROJECT](https://raw.githubusercontent.com/limlining/SECR-DIGITAL-LOGIC/main/project.jpg)

      GROUP MEMBER: LIM LI NING, LIM LI JING , CHENG ZHI MIN ,NG XUAN YEE

This project designs and implements a 4-floor elevator control system based on D flip-flops, integrating advanced features such as password verification and status indication. The system employs digital logic circuit design with D flip-flops as core storage elements, suitable for implementation on FPGA or digital circuit experimental platforms.

🎯Key Features：

1.**Core Logic:** State registers composed of D flip-flops for floor control

2.**Security Features:** 4-digit password verification for accessing specific floors

3.**Visual Display:** LED floor indicators + 7-segment display

4.**Complete Functionality:** Supports normal scheduling, arrival notification

📝REFLECTION:

A comprehensive understanding of the synergy between sequential and combinational logic was achieved through the architecture of this 4-floor elevator control system. At the core of the design, a Finite State Machine (FSM) was modeled using negative edge-triggered D flip-flops to maintain the state of the current floor. The transition logic was derived through the meticulous formulation of state transition tables and Karnaugh Maps (K-maps), ensuring that the next-state excitation equations accurately dictated the motor’s directional movement and stopping sequence based on multi-input calls.

One of the primary technical hurdles involved the synchronization of asynchronous input signals from various floor buttons with the system’s global clock. Inconsistent signal timing initially led to "race conditions" or erratic state jumps. To resolve this, a debouncing logic and a clock-enable synchronization strategy were implemented and verified within the simulation environment. By tracking the signal propagation through Boolean algebra and timing diagrams, the stability of the flip-flop inputs was secured, allowing for smooth transitions between floor levels without state oscillations.

Furthermore, the integration of a 4-digit password authentication module expanded the project’s scope into secure digital system design. This required the interfacing of a comparator circuit with a sequential input buffer to validate security codes before granting access to restricted floors. The coordination between the 7-segment display decoders and the status LEDs further reinforced the importance of clear visual feedback in hardware-software interaction. Ultimately, this project has solidified my proficiency in designing multi-layered digital architectures and has provided a robust foundation for future explorations into FPGA prototyping and complex logic synthesis.
